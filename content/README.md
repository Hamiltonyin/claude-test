# 每日课程内容

每天新增一个 CSV 文件，例如 `day-003.csv`（UTF-8，列：`day,thai,roman,zh,theme,exTh,exRoman,exZh`），推送到 main 后：

1. 流水线校验泰文/声调、合并到 `public/content/library.json`；
2. 只为**新词**生成音频（已有音频不会重做）；
3. 重新部署。用户设备在线打开应用时自动合并新增课程，**不会改动已有词条与学习记录**。

已存在的词（泰文相同）会复用原来的词汇 ID 和熟练度，只是归入当天课程。

## 选词规则（每日30词）

1. 只收日常生活里真正会用到的高频词：会话、出行、吃饭、购物、居家、看病、上班。
2. 优先短词和能直接造句的词；例句用真实场景里的话。
3. 不收冷僻词、纯书面语、专业术语和过长的复合词。
4. 每批与已有词条去重；拼音声调按泰语规则逐个核对（`npm run check:data` + 构建时自动校验）。
5. 目标：词库累计 500 词（已达成，第 1~17 天）。

## 批量编写工具

`content/src/*.txt` 是 500 词的源文件（`# day N` 分天，每行 `泰文|声调码|拼音|中文|主题|例句泰文|例句拼音|例句中文`）。
`node scripts/author-days.mjs` 会校验后生成 `content/day-0NN.csv`：
- 声调码（M中 L低 F降 H高 R升）由作者按泰语规则独立标注，必须与拼音上的声调符号完全一致；
- 泰文必须是纯泰文字符、不得与已有词重复、必填项齐全。
