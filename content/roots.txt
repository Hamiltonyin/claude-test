# 构词规律：`部件|一句话规律`。页面会自动列出这个部件出现在哪些词里（出现 ≥3 次的才显示）。
ผู้|ผู้ + 名词/动词 ＝ 「做…的人」。ผู้ชาย 男人、ผู้หญิง 女人。
นัก|นัก + 动词 ＝ 「专门做这事的人」。นักเรียน 学生、นักร้อง 歌手。
ความ|ความ + 动词/形容词 ＝ 抽象名词（…性、…这件事）。ความสุข 快乐、ความหมาย 意思。
ที่|ที่ + 动词/指示词 ＝ 「…的地方」。ที่นี่ 这里、ที่อยู่ 住址；วันที่ 里是「第」。
ข้าง|ข้าง + 方位词 ＝ 某一侧。ข้างหน้า 前边、ข้างซ้าย 左边。
ใจ|「某某 + ใจ」＝ 和心情有关：ดีใจ 高兴、เสียใจ 难过、ตกใจ 吓一跳、ตั้งใจ 用心。
น้ำ|น้ำ ＝ 水，也指汁、液体：น้ำจิ้ม 蘸料、น้ำตาล 糖。
ห้อง|ห้อง + X ＝ X 房间：ห้องน้ำ、ห้องพัก、ห้องเช่า。
โรง|โรง + X ＝ 做 X 的场所：โรงเรียน 学校、โรงแรม 酒店、โรงพยาบาล 医院。
ร้าน|ร้าน + X ＝ 卖 X 的店：ร้านอาหาร 餐馆。
ขี้|ขี้ + X ＝ 「爱…的、容易…的」：ขี้เกียจ 懒、ขี้โกหก 爱撒谎。
มะ|มะ 是水果名常见前缀：มะม่วง 芒果、มะพร้าว 椰子。
ใบ|ใบ + X ＝ X 这张单据/一片：ใบเสร็จ 收据、ใบแจ้งหนี้ 账单。
วัน|วัน + 天体 ＝ 星期几（月亮=一、火星=二、水星=三、木星=四、金星=五、土星=六、太阳=日）。
สิบ|个位数 + สิบ ＝ 整十：สามสิบ 30。二十是 ยี่สิบ，十一是 สิบเอ็ด。
ร้อย|个位数 + ร้อย ＝ 整百：สองร้อย 200。
ของ|ของ + 人称 ＝ 「…的」：ของผม 我的；ของ + 形容词 ＝ …的东西：ของแท้ 正品。
ค่า|ค่า + X ＝ X 的费用：ค่าเช่า 房租。
พระ|พระ + X ＝ 佛/僧相关：พระแท้ 真佛牌、พระปิดตา 闭眼佛。
ข้าว|ข้าว + X ＝ 饭类：ข้าวผัด 炒饭、ข้าวเหนียว 糯米饭。
ไม่|ไม่ + 动词/形容词 ＝ 否定：ไม่มี 没有、ไม่เข้าใจ 不懂。
กัน|动词 + กัน ＝ 互相/一起：เจอกัน 见面、ด้วยกัน 一起。
หน้า|หน้า 前面/脸/下一个：ข้างหน้า 前边、ปีหน้า 明年。
ทำ|ทำ + 名词 ＝ 做某事：ทำงาน 工作、ทำอาหาร 做饭。
เงิน|เงิน + 动词 ＝ 钱相关：จ่ายเงิน 付钱、คิดเงิน 结账。
รถ|รถ ＝ 车：นั่งรถ 坐车、ขับรถ 开车、รถไฟ 火车。
ร้อง|ร้อง + 名词/动词 ＝ 发出声音：ร้องเพลง 唱歌、ร้องไห้ 哭。
เช่า|เช่า ＝ 租：ห้องเช่า 出租房、ให้เช่า 出租、ค่าเช่า 房租。
ผ้า|ผ้า ＝ 布：ซักผ้า 洗衣服、ผ้าห่ม 被子。
พอ|พอ ＝ 够：พอดี 正好、พอจะ 大致能。
